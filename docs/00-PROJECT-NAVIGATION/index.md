## 📋 Quick Reference

### Company Identity

- **Type:** Founder-Led Product Studio
- **Mission:** Build innovative digital products and empower founders to do the same
- **Founder Thesis:** Prove world-class products can be built from India
- **Model:** Internal products + Client services

### Internal Products

| Product | Status | Description |
|---------|--------|-------------|
| **Clinax** | MVP Development | Healthcare telemedicine platform |
| **Halo** | Concept | Patient engagement platform |
| **TrueBill** | Production | Billing automation (live with customers) |
| **TafsirAI** | Concept | AI-powered Quranic insights |

### Strategic Non-Negotiables

1. Founder-Led Product Studio positioning remains primary
2. Healthcare expertise is differentiator, not limitation
3. Internal products remain visible
4. Founder story remains trust asset
5. Claims must remain evidence-based
6. Product studio model explained in plain language
7. Dual model is core to identity
8. Ground work over assumptions
9. Outcomes over output
10. Capability is learned, not inherited
11. Internal products never presented as client work

## 🎨 Design Standards

### Typography

- **Headings:** Poppins via `font-heading`
  - Hero H1: `font-black` (900)
  - Section H2: `font-extrabold` (800)
  - Card titles: `font-semibold` (600)
- **Body:** Inter via `font-sans`
  - Light bg: `text-gray-600`
  - Dark bg: `text-slate-300`

### Colors

- **Primary Brand:** Orange `#F97316`
- **CTA Gradient:** `from-yellow-500 to-orange-500`
- **Service Cards:** Whisper-soft borders `border-gray-100/80`

### Design Philosophy

- Apple/Stripe restraint
- Fewer layers, generous whitespace
- Scannable content
- One gradient accent per section max
- Typography-driven hierarchy
- Subtle interactivity

### Setup

```bash
pnpm install
cp env-example.txt .env.local
# Edit .env.local with SMTP credentials
pnpm dev
```

### Key Commands

```bash

pnpm start        # Start production server
pnpm lint         # Run ESLint
```
