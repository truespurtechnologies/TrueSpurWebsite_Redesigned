# TrueSpur Visual Design Prioritization Plan

**Date:** June 4, 2026  
**Purpose:** Prioritize design work to prevent premature optimization  
**Framework:** NOW / NEXT / LATER  

---

## PHILOSOPHY

**Core Principle:** Positioning and credibility before visual perfection.

**Why This Matters:**
- A beautifully designed website with weak positioning = low conversions
- A well-positioned website with good design = high conversions
- Visual polish is the final 10%, not the first 90%

**Strategy:**
- **NOW:** Design elements critical to positioning and credibility
- **NEXT:** Design improvements that enhance trust and conversion
- **LATER:** Premium polish that can wait until positioning is proven

## DESIGN DECISION FRAMEWORK

### **How to Decide: NOW vs NEXT vs LATER**

**Ask These Questions:**

1. **Does this support positioning?**
   - YES → NOW
   - NO → NEXT or LATER

2. **Does this build credibility/trust?**
   - YES → NOW
   - NO → NEXT or LATER

3. **Is this critical for conversion?**
   - YES → NOW
   - MAYBE → NEXT
   - NO → LATER

4. **Can we launch without it?**
   - NO → NOW
   - YES, but it helps → NEXT
   - YES, easily → LATER

5. **Is positioning proven?**
   - NO → Defer to LATER
   - YES → Consider NEXT

## DESIGN PRINCIPLES (Reminder)

Based on existing design system and brand guidelines:

### **1. Restraint Over Decoration**
- Fewer layers, more whitespace
- Typography-driven hierarchy
- One gradient accent per section max

### **2. Human-Crafted Feel**
- Avoid AI-template patterns
- Subtle, not flashy
- Premium, not gimmicky

### **3. Scannable Content**
- Clear visual hierarchy
- Generous whitespace
- Mobile-first thinking

### **4. Subtle Interactivity**
- Hover states (shadow-sm → shadow-lg)
- Smooth transitions (200-300ms)
- Lift on hover (-4px)

### **5. Integration Over Decoration**
- Floating bridge elements
- Contextual CTAs
- Seamless section flow
